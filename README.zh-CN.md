## 概述

Windows 默认会把网络数据先攒一会儿再一起发送。这对下载文件、浏览网页来说很高效,但在网络游戏中,每一次按键都需要立刻送达服务器,这样做反而会让游戏响应变慢。

BoostPing 会把这类设置中的 5 项调整为适合游戏的状态。按下 **[开始加速]**,它会找到当前连接互联网的网络,应用设置并重新连接网络。按下 **[关闭加速]**,则会精确恢复到应用之前的原始值。要更改哪些项目由你自己选择,未勾选的项目完全不会被改动。

## 主要功能

- **一键应用** — 无需复杂设置,按一下 [开始加速] 即可。
- **自动找到当前使用的网络** — 选出真正连接互联网的网卡,并在窗口底部显示其名称和 IP。虚拟网卡会被跳过。
- **5 个项目按需应用** — ACK 立即响应、ACK 无延迟、禁用 Nagle 算法、解除网络限制、游戏优先处理。
- **精确恢复原状** — 记住加速前的值,关闭时原样恢复。原本不存在的设置会被删除,你自己改过的值会恢复为那个值。
- **关闭程序后仍然有效** — 设置应用在 Windows 中,因此关闭窗口或重启后效果依然保持。再次运行时会如实显示已应用的状态。
- **9 种语言** — 韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语 · 阿拉伯语 · 西班牙语。跟随 Windows 显示语言。

## 使用方法

### 第一次使用

1. 运行 BoostPing。由于它会修改 Windows 设置,弹出管理员权限确认窗口时请点 **[是]**。
2. 确认窗口最下方显示了当前所用网络的名称和 IP。(例: `以太网 (Realtek PCIe GbE Family Controller) · 192.168.0.10`)
3. 如需选择要更改的项目,点右上角的**设置图标**进入 **TUNING** 界面。初始时 5 项全部开启。
4. 点 **[开始加速]**。状态变为 **BOOST**,并显示"正在重新连接网络…"。此时互联网会短暂断开后重新连接。
5. 互联网恢复后,状态变为 **ON**,显示"优化已应用"。现在启动游戏即可。
6. 想恢复原状时,点 **[关闭加速]**。网络会再重新连接一次,状态回到 **READY**。

### 界面说明

**主界面**

| 元素 | 说明 |
|---|---|
| **BOOST//PING** 标志 | 点击打开 BoostPing 主页 |
| 设置图标 (右上角) | 进入 TUNING 界面 |
| **STATUS** | **READY** = 待机,**BOOST** = 应用中,**ON** = 已应用 |
| 5 条进度条 · **%d / 5 项** | 已开启的项目数,一条对应一个项目 |
| **[开始加速]** / **[关闭加速]** | 应用 / 恢复原状 |
| 最下面一行 | 当前网络名称 · IP、程序版本 |

**TUNING 界面** — 点击项目即可开启或关闭,更改会立即保存。

| 项目 | 作用 |
|---|---|
| **ACK 立即响应** | 不合并确认,收到数据后立即发送 |
| **ACK 无延迟** | 将确认延迟计时器设为 0 |
| **禁用 Nagle 算法** | 不合并小数据包,立即发送 |
| **解除网络限制** | 解除媒体播放时的传输限制 |
| **游戏优先处理** | 不再为后台保留 CPU 时间 |

### 这种情况怎么办

**游戏中感觉操作慢半拍时**
在启动游戏之前,先在 BoostPing 中点 [开始加速]。越是频繁收发小数据的网络游戏,越容易感受到效果。应用时互联网会短暂重新连接,所以最好在进入对局**之前**开启。

**想开一次就一直用时**
开启加速后,可以直接关闭 BoostPing 窗口。设置保留在 Windows 中,重启后依然处于已应用状态。再次运行 BoostPing 时,状态会显示为 **ON**。

**边放音乐或直播边玩游戏时**
Windows 在播放媒体期间会限制网络传输。开启 **解除网络限制** 后,即使开着音乐或视频,也不会受到这一限制。

**只想应用部分项目时**
在加速关闭 (READY) 的状态下,点设置图标 → TUNING 界面,点击不需要的项目将其关闭。主界面的进度条和 **%d / 5 项** 会立即变化。关闭的项目无论开始还是关闭加速时都完全不会被改动。

**加速开启时想更改项目**
加速开启期间,TUNING 界面会被锁定,并显示"关闭加速后才能更改。"。请按 [关闭加速] → 更改项目 → [开始加速] 的顺序操作。

**想对比效果时**
用 [关闭加速] 在原始状态下玩一局,再用 [开始加速] 在应用后的状态下玩一局。关闭后会精确恢复到应用前的值,因此可以来回切换对比任意多次。

**以前自己改过网络设置时**
BoostPing 在开始前会记住当前的值。关闭时恢复的不是 Windows 默认值,而是**你自己设置的那个值**。

**笔记本在 Wi‑Fi 和有线之间切换使用时**
加速应用于开始时正在使用的网络。如果切换了网络,请先点 [关闭加速],然后关闭 BoostPing 再重新运行。窗口底部显示新网络后,再点 [开始加速]。关闭加速时,即使中途切换过网络,也会把最初应用的那个网络恢复原状。

**玩完游戏想恢复原状时**
运行 BoostPing,点 [关闭加速] 即可。卸载程序之前,也请先关闭加速。

**找不到 BoostPing 窗口时**
BoostPing 同一时间只能运行一个。已经在运行时再次启动,会把先打开的窗口调到最前面(如果已最小化则会还原)。

## 设置

在 TUNING 界面中更改,更改会立即保存,更新后依然保留。

| 项目 | 默认值 |
|---|---|
| ACK 立即响应 | 开启 |
| ACK 无延迟 | 开启 |
| 禁用 Nagle 算法 | 开启 |
| 解除网络限制 | 开启 |
| 游戏优先处理 | 开启 |

界面语言跟随 Windows 显示语言(韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语 · 阿拉伯语 · 西班牙语,其他语言显示英语)。阿拉伯语从右向左显示。
